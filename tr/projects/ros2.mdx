## 1. Amaç

T3 Gemstone üzerinde kullanılan Ubuntu 22.04 tabanlı minimal sistem imajında,
ROS 2 Humble kurulumu için gerekli paket kaynakları ve bazı sistem bileşenleri
varsayılan olarak hazır olmayabilir. Bu durum doğrudan ROS 2 kurulumu
denendiğinde paketlerin bulunamaması veya bağımlılık sorunlarıyla
karşılaşılmasına neden olabilir.

Bu doküman, T3 Gemstone kartının Ubuntu 22.04 Jammy ile hazırlanmasını ve
ROS 2 Humble `ros-base` kurulumunun tekrar edilebilir bir şekilde
gerçekleştirilmesini amaçlar.

Kurulum; sistemin hazırlanması, ağ ve paket yöneticisinin doğrulanması,
ROS 2 APT kaynağının eklenmesi, ROS 2 Humble'ın kurulması ve kurulumun
test edilmesi adımlarından oluşur.

## 2. Kullanılan sistem

| Bileşen | Bilgi |
|---|---|
| Kart | T3 Gemstone |
| Mimari | AArch64 / ARM64 |
| İşletim sistemi | Ubuntu 22.04 Jammy Jellyfish |

## 3. Özel Ubuntu imajını karta yazma

### 3.1 İmaj yazma uygulamasıyla karta imaj yazma
Bu konu T3 Gemstone dokümantasyonunda anlatılmıştır. Detaylara [buradan ulaşabilirsiniz](https://docs.t3gemstone.org/tr/imager/customization).
### 3.2 SD karta yazma
1. T3 Gemstone için hazırlanan `.img` dosyasını bilgisayarınıza indirin. Bkz. [T3 Gemstone imajları](https://packages.t3gemstone.org/images/ubuntu/jammy/t3-gem-o1/)
2. SD kartınızı bilgisayara takın.
3. Ubuntu'da **Diskler (Disks)** uygulamasını açın.
4. Sol menüden doğru SD kartı seçin.
5. Menüden **Disk Kalıbını Geri Yükle / Restore Disk Image** seçeneğini açın.
6. Aşağıdaki imajı seçin:

```text
gemstone-minimal-v2026.2-ubuntu-jammy-t3-gem-o1.img
```

7. Yazma işlemini başlatın ve yüzde 100 tamamlanmasını bekleyin.
8. SD kartı güvenli biçimde çıkarın.
9. SD kartı T3 Gemstone'a takıp kartı başlatın.

> **Dikkat:** Yanlış disk seçilirse o diskteki bütün veriler silinir. Bu yüzden seçtiğiniz diski iki kere kontrol edip emin olmanız önerilir.

## 5. İnternet ve DNS kontrolü

Önce doğrudan internet erişimini test edin:

```bash
ping -c 3 8.8.8.8
```

Ardından alan adı çözümlemesini test edin:

```bash
getent hosts github.com
getent hosts packages.ros.org
getent hosts packages.t3gemstone.org
```

IP adresine ping çalışıyor fakat alan adları çözülemiyorsa DNS'i yenileyin:

```bash
IFACE=$(ip route | awk '/default/ {print $5; exit}')

sudo systemctl restart systemd-resolved
sudo resolvectl dns "$IFACE" 1.1.1.1 8.8.8.8
sudo resolvectl flush-caches
```

Tekrar kontrol edin:

```bash
getent hosts packages.ros.org
```

## 6. Paket sistemini düzeltme ve güncelleme

Yarım kalan paket işlemlerini tamamlayın:

```bash
sudo dpkg --configure -a
sudo apt --fix-broken install
sudo apt clean
sudo rm -rf /var/lib/apt/lists/*
sudo apt update
sudo apt upgrade -y
```

T3 Gemstone imajında Ubuntu Jammy güncelleme ve güvenlik depoları eksikse
`jammy-updates` ve `jammy-security` depolarının etkin olduğundan emin olun.

Sistemi doğrulamak için:

```bash
grep -R "jammy" /etc/apt/sources.list /etc/apt/sources.list.d/ 2>/dev/null
```

## 7. ROS 2 Humble Kurulumu

ROS 2 Humble, Ubuntu 22.04 Jammy için hazırlanmıştır. Gemstone üzerinde daha hafif bir kurulum için `ros-base` tercih edilir.

Kuruluma başlamadan önce sistemin paket listesini güncelleyin:

```bash
sudo apt update
```

### 7.1. ROS 2 Kurulumu İçin Gerekli Araçların Kurulması

ROS 2 APT deposunun sisteme eklenebilmesi için gerekli temel araçları kurun:

```bash
sudo apt install -y \
curl \
gnupg \
lsb-release \
software-properties-common
```

Kurulumdan sonra gerekli komutların sistemde bulunduğunu kontrol edin:

```bash
command -v curl
command -v add-apt-repository
```

Beklenen çıktı:

```text
/usr/bin/curl
/usr/bin/add-apt-repository
```

Örnek terminal çıktısı:

```text
gemstone@t3-gem-o1:~$ command -v curl
/usr/bin/curl

gemstone@t3-gem-o1:~$ command -v add-apt-repository
/usr/bin/add-apt-repository
```

Universe deposunu etkinleştirin:

```bash
sudo add-apt-repository universe
```

Ardından paket listesini tekrar güncelleyin:

```bash
sudo apt update
```

---

### 7.2. ROS 2 APT Kaynağının Eklenmesi

ROS 2 paketlerini `apt` ile kurabilmek için ROS APT kaynağının sisteme eklenmesi gerekir.

Öncelikle güncel ROS APT kaynak paketi sürümünü alın:

```bash
export ROS_APT_SOURCE_VERSION=$(curl -s \
https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest \
| grep -F "tag_name" \
| awk -F\" '{print $4}')
```

Alınan sürüm bilgisini kontrol edin:

```bash
echo "$ROS_APT_SOURCE_VERSION"
```

Komut boş olmayan bir sürüm değeri döndürmelidir.

Ardından sistemin Ubuntu sürüm kod adını kullanarak uygun ROS 2 APT kaynak paketini indirin:

```bash
curl -L \
-o /tmp/ros2-apt-source.deb \
"https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo $VERSION_CODENAME)_all.deb"
```

İndirilen `.deb` paketini kurun:

```bash
sudo dpkg -i /tmp/ros2-apt-source.deb
```

ROS deposu eklendikten sonra paket listesini yeniden güncelleyin:

```bash
sudo apt update
```

> **Not:**  
> `Unable to locate package ros-humble-ros-base` hatası alınıyorsa ROS 2 APT kaynağı henüz doğru şekilde eklenmemiş veya `sudo apt update` işlemi başarıyla tamamlanmamış olabilir.

### 7.3. ROS 2 Humble ROS Base Kurulumu

Kuruluma geçmeden önce paketin sistem tarafından bulunabildiğini ve bağımlılıkların çözülebildiğini kontrol etmek için kurulumu simüle edin:

```bash
sudo apt install --simulate ros-humble-ros-base
```

Simülasyon herhangi bir paket bulunamadı hatası vermiyorsa ROS 2 Humble ROS Base paketini kurun:

```bash
sudo apt install -y ros-humble-ros-base
```

`ros-base`, masaüstü ve GUI araçlarını içeren daha büyük ROS 2 Desktop kurulumu yerine, Gemstone gibi gömülü sistemlerde kullanılabilecek daha hafif bir ROS 2 kurulumu sağlar.

## 8. ROS 2 Ortamının Etkinleştirilmesi

ROS 2 kurulmuş olsa bile ROS komutlarının kullanılabilmesi için ROS ortamının terminal oturumuna yüklenmesi gerekir.

### 8.1. Mevcut Terminal İçin ROS 2 Ortamını Etkinleştirme

Mevcut terminal oturumunda ROS 2 Humble ortamını etkinleştirin:

```bash
source /opt/ros/humble/setup.bash
```

Bu komut yalnızca mevcut terminal için geçerlidir. Terminal kapatıldığında tekrar çalıştırılması gerekir.

---

### 8.2. ROS 2 Ortamını Kalıcı Olarak Etkinleştirme

Her yeni terminal açıldığında ROS 2 ortamının otomatik olarak yüklenmesi için aşağıdaki komutu çalıştırın:

```bash
grep -qxF 'source /opt/ros/humble/setup.bash' ~/.bashrc || \
echo 'source /opt/ros/humble/setup.bash' >> ~/.bashrc
```

Bu yöntem, aynı satırın `.bashrc` dosyasına birden fazla kez eklenmesini engeller.

Değişiklikleri mevcut terminale uygulayın:

```bash
source ~/.bashrc
```

---

### 8.3. ROS 2 Kurulumunun Kontrol Edilmesi

Aktif ROS dağıtımını kontrol edin:

```bash
echo "$ROS_DISTRO"
```

Beklenen çıktı:

```text
humble
```

ROS 2 komut satırı aracının çalıştığını kontrol edin:

```bash
ros2 --help
```

Beklenen çıktının başlangıcı aşağıdaki gibi olmalıdır:

```text
usage: ros2 [-h] [--use-python-default-buffering]

ros2 is an extensible command-line tool for ROS 2.

options:
  -h, --help
```

ROS 2 tarafından kullanılabilir komutlar arasında aşağıdakiler bulunmalıdır:

```text
Commands:
  action
  bag
  component
  daemon
  doctor
  interface
  launch
  lifecycle
  multicast
  node
  param
  pkg
  plugin
  run
  security
  service
  topic
```

Son olarak `ros-humble-ros-base` paketinin sistemde kurulu olduğunu doğrulayın:

```bash
dpkg -l | grep ros-humble-ros-base
```

Başarılı bir kurulumda aşağıdakine benzer bir çıktı görülmelidir:

```text
ii  ros-humble-ros-base  0.10.0-1jammy.20260607.150006  arm64  A package which extends 'ros_core' and includes other basic functionalities like tf2 and urdf.
```

> Paket sürüm numarası zaman içerisinde değişebilir. Kontrol edilmesi gereken temel nokta, satırın `ii` ile başlaması ve `ros-humble-ros-base` paketinin listelenmesidir.

## 9. Basit topic haberleşme testi

### Terminal 1 — yayıncı

```bash
source /opt/ros/humble/setup.bash

ros2 topic pub /test_konusu std_msgs/msg/String "{data: 'Selam T3 Gemstone'}"
```

### Terminal 2 — dinleyici

```bash
source /opt/ros/humble/setup.bash

ros2 topic echo /test_konusu
```

Mesaj görünüyorsa temel ROS 2 haberleşmesi çalışmaktadır.

## 10. `demo_nodes_cpp` bulunamadı hatası

`ros-humble-ros-base` hafif kurulumdur ve demo paketleri varsayılan olarak
gelmeyebilir.

Gerekirse:

```bash
sudo apt install -y ros-humble-demo-nodes-cpp
```

Test:

```bash
ros2 run demo_nodes_cpp talker
```

Başka terminalde:

```bash
ros2 run demo_nodes_cpp listener
```
