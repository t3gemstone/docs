title: 'RTC'

---

لكي تتمكن الحواسيب من مواصلة عدّ ساعة النظام أثناء انقطاع التيار أو حالات الإغلاق والتشغيل، يُستخدم عتاد
يسمى RTC (Real-Time Clock) يعمل ببطارية خارجية.

<Note>
  توجد ساعة RTC في لوحة T3-GEM-O1. إذا لم تستخدم وحدة RTC، فعند فصل طاقة اللوحة وإعادة توصيلها
  تُصفَّر ساعة النظام وتبدأ من تاريخ 01/01/1970.
  إذا كانت اللوحة متصلة بالإنترنت، فسيُضبط الوقت الصحيح بعد فترة. أما إذا كنت تريد أن يبقى الوقت صحيحًا
  دون إنترنت، فيجب استخدام RTC.
</Note>

### خطوات تشغيل RTC

<Steps>

  <Step title="وصّل البطارية">
    <Frame caption="مهام معلّقة: توصيل بطارية RTC">
      <img style={{height: "300px", width: "auto"}} className="rounded-lg" noZoom src="/images/under-construction.png" />
    </Frame>
  </Step>

  <Step title="أرسل معلومات التاريخ والوقت الحالية">
  ثم افتح طرفية عبر [المنفذ التسلسلي](../../../quickstart#2-1-المنفذ-التسلسلي) أو
  [SSH](../../../quickstart#2-3-الاتصال-عبر-الشبكة-باستخدام-ssh).
  يجب إرسال ساعة نظامك إلى وحدة RTC لمرة واحدة فقط باستخدام الأمر التالي.

  ```bash
  gemstone@t3-gem-o1:~$ sudo hwclock -w -u /dev/rtc0
  ```

  إذا نجحت العملية، فعند تشغيل الأمر `hwclock -r` يجب أن ترى ناتجًا مشابهًا لما يلي.

  <CodeGroup>
  ```bash Terminal
  gemstone@t3-gem-o1:~$ sudo hwclock -r
  ```

  ```bash Output
  2025-07-16 08:25:02.160359+03:00
  ```
  </CodeGroup>

  </Step>

  <Step title="اختبر">
  أوقف تشغيل لوحتك بزر الطاقة الموجود عليها أو بالأمر `poweroff` وافصل كابل الطاقة.
  بعد الانتظار حوالي 10 ثوانٍ، أعد توصيل الطاقة للوحة وشغّل الأمر `date`. إذا كانت معلومات
  التاريخ والوقت المعروضة صحيحة، فهذا يعني أن RTC يعمل دون مشاكل.
  </Step>

</Steps>
