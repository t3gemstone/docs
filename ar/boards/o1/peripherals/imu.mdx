وحدة قياس القصور الذاتي (IMU) هي جهاز استشعار يقيس ويبلّغ عن الحركة والاتجاه وقوى الجاذبية. تجمع وحدات IMU
بين عدة مستشعرات لتوفير قدرات تتبع حركة شاملة تجعلها لا غنى عنها في تطبيقات مثل الروبوتات وتثبيت الطائرات
بدون طيار واستشعار الحركة وتتبع الاتجاه وأنظمة الملاحة.

تدمج وحدات IMU الحديثة عادةً مقياس تسارع ثلاثي المحاور (يقيس التسارع الخطي)، وجيروسكوب ثلاثي المحاور (يقيس
السرعة الزاوية)، وغالبًا مقياس مغناطيسية ثلاثي المحاور (يقيس المجال المغناطيسي) لتكوين حل تتبع حركة متكامل
بتسعة محاور.

## 1\. ICM-20948 IMU

لوحتك مزودة بجهاز تتبع الحركة عالي الأداء ذي التسعة محاور InvenSense ICM-20948. يحتوي المستشعر في حزمة واحدة
على جيروسكوب ثلاثي المحاور ومقياس تسارع ثلاثي المحاور ومقياس مغناطيسية ثلاثي المحاور.

### 1\.1\. الميزات الأساسية

- **جيروسكوب ثلاثي المحاور** بنطاقات قياس كاملة قابلة للبرمجة: ±250، ±500، ±1000، ±2000 DPS
- **مقياس تسارع ثلاثي المحاور** بنطاقات قياس كاملة قابلة للبرمجة: ±2g، ±4g، ±8g، ±16g
- **مقياس مغناطيسية ثلاثي المحاور** (AK09916) لوظيفة البوصلة
- **مستشعر حرارة بمخرج رقمي** لتعويض الحرارة
- **مقاطعات قابلة للبرمجة من قبل المستخدم** لاستشعار الحركة وإشارات جاهزية البيانات
- **أوضاع استهلاك طاقة منخفض** للتطبيقات التي تعمل بالبطارية
- **مرشح رقمي منخفض التمرير (DLPF)** لتقليل الضوضاء

### 1\.2\. التوصيل العتادي

ICM-20948 الموجود على لوحتك متصل عبر واجهة SPI على العنوان `/dev/spidev0.3`.

## 2\. تطبيق مثال

مشروع `imu` الموجود في مستودع [t3gemstone/examples](https://github.com/t3gemstone/examples) يوفر مكتبة C كاملة
وتطبيق اختبار للتفاعل مع مستشعر IMU. تدير المكتبة جميع الاتصالات منخفضة المستوى وتوفر واجهة برمجية (API)
لقراءة بيانات المستشعر.

### 2\.1\. تطبيق الاختبار

ينفذ تطبيق الاختبار الخطوات التالية:

1. **التهيئة** - يفتح جهاز SPI على العنوان `/dev/spidev0.3` ويشغّل المستشعر
2. **الإعداد** - يضبط مقياس التسارع على نطاق ±8g والجيروسكوب على نطاق ±2000 DPS
3. **الإعلام** - يطبع قيم الإعداد ودرجة الحرارة في البداية
4. **المراقبة المستمرة** - يقرأ بيانات مقياس التسارع والجيروسكوب كل 10ms ويطبع الزوايا المحسوبة
5. **حساب الزوايا** - يطبّق ترشيح Kalman لحساب زوايا الاتجاه
6. **الاسترداد التلقائي** - يراقب اتصال المستشعر ويعيد تهيئته عند الحاجة

<Tip>
يوفر تطبيق مرشح Kalman تقديرات زوايا سلسة بدمج بيانات مقياس التسارع والجيروسكوب، مما يقلل الضوضاء
مع الحفاظ على الحساسية تجاه الحركة الحقيقية.
</Tip>

### 2\.2\. مرجع واجهة API

توفر مكتبة `icm20948` ما يلي:

- **تهيئة الناقل** لواجهتي I2C وSPI
- **إعداد المستشعر** بنطاقات قياس كاملة قابلة للتخصيص
- **قراءة البيانات الخام** لمقياس التسارع والجيروسكوب ودرجة الحرارة
- **حساب الزوايا** باستخدام ترشيح Kalman لتتبع الاتجاه بسلاسة
- **استرداد تلقائي** مع فحص الحالة أثناء الاتصال وإعادة الإعداد
- **وصول مرن إلى البيانات** عبر واجهة بيانات منظّمة

#### 2\.2\.1\. التهيئة

```c
icm20948_handle_t icm20948_create(icm20948_data_t* data, char* tag);
int icm20948_spi_bus_init(icm20948_handle_t sensor, const char* dev_path);
int icm20948_configure(icm20948_handle_t sensor, 
                       icm20948_acce_fs_t acce_fs, 
                       icm20948_gyro_fs_t gyro_fs);
```

#### 2\.2\.2\. قراءة البيانات

```c
int icm20948_get_acce(icm20948_handle_t sensor);
int icm20948_get_gyro(icm20948_handle_t sensor);
int icm20948_get_temp(icm20948_handle_t sensor);
void icm20948_get_angle(icm20948_handle_t sensor, float dt);
```

#### 2\.2\.3\. الإعداد

```c
int icm20948_set_acce_fs(icm20948_handle_t sensor, icm20948_acce_fs_t acce_fs);
int icm20948_set_gyro_fs(icm20948_handle_t sensor, icm20948_gyro_fs_t gyro_fs);
float icm20948_get_acce_sensitivity(icm20948_handle_t sensor);
float icm20948_get_gyro_sensitivity(icm20948_handle_t sensor);
```

#### 2\.2\.4\. الأدوات المساعدة

```c
int icm20948_check_online(icm20948_handle_t sensor);
void icm20948_delete(icm20948_handle_t sensor);
```

#### 2\.2\.5\. بنية البيانات

يُوصَل إلى بيانات المستشعر عبر البنية `icm20948_data_t`:

```c
typedef struct {
    int16_t ax_raw, ay_raw, az_raw; // بيانات مقياس التسارع الخام
    int16_t gx_raw, gy_raw, gz_raw; // بيانات الجيروسكوب الخام
    float ax, ay, az;               // مقياس التسارع (g)
    float gx, gy, gz;               // الجيروسكوب (درجة/ث)
    float anglex, angley, anglez;   // الزوايا المحسوبة (درجة)
    float temp;                     // درجة الحرارة (°C)
} icm20948_data_t;
```
