يوضح هذا القسم كيفية استخدام نماذج معالجة الصور التي أعددتها بمجموعة بياناتك الخاصة أو حصلت عليها جاهزة.

```bash
sudo su
source /opt/t3-edgeai-env
```

تتيح لك هذه الأوامر التبديل إلى المستخدم `root` وتحميل متغيرات البيئة اللازمة لـ Edge AI.

<Tip>إذا لم يكن ملف متغيرات البيئة موجوداً، فيمكنك تثبيت الحزمة المعنية من قسم [تثبيت Edge AI](/ar/boards/o1/ai/installation).</Tip>

## Edge AI GStreamer Apps

هذا المشروع عبارة عن مجموعة من التطبيقات المرجعية مفتوحة المصدر توفرها Texas Instruments ويمكن استخدامها
لتطوير تطبيقات الذكاء الاصطناعي بسرعة على أجهزة مثل T3 Gemstone O1. يعمل المشروع أساساً ببنية مبنية على
GStreamer ويقدم حلولاً جاهزة لتنفيذ معالجة الصور واكتشاف الأجسام والبث (streaming) وغيرها من سير عمل الذكاء
الاصطناعي على معالجات Texas Instruments وعتاد SoC.

عند إجراء تثبيت Edge AI المذكور في قسم التثبيت، يمكنك الوصول إلى هذا المشروع من المجلد `/opt/edgeai-gst-apps`.

يوجد داخل مجلد Configs أمثلة لأكثر من تطبيق. وهو يتيح لك تشغيل المشروع بلغتي Python وC++.

على سبيل المثال، الإعداد الموجود داخل `configs/image_classification.yaml` هو كما يلي.

```yaml
title: "Image Classification"
log_level: 2
inputs:
    input0:
        source: /dev/video-usb-cam0
        format: jpeg
        width: 1280
        height: 720
        framerate: 30
    input1:
        source: /opt/edgeai-test-data/videos/video0_1280_768.h264
        format: h264
        width: 1280
        height: 768
        framerate: 30
        loop: True
    input2:
        source: /opt/edgeai-test-data/images/%04d.jpg
        width: 1280
        height: 720
        index: 0
        framerate: 1
        loop: True
models:
    model0:
        model_path: /opt/model_zoo/TVM-CL-3090-mobileNetV2-tv
        topN: 5
    model1:
        model_path: /opt/model_zoo/TFL-CL-0000-mobileNetV1-mlperf
        topN: 5
    model2:
        model_path: /opt/model_zoo/ONR-CL-6360-regNetx-200mf
        topN: 5
outputs:
    output0:
        sink: kmssink
        width: 1920
        height: 1080
        overlay-perf-type: graph
    output1:
        sink: /opt/edgeai-test-data/output/output_video.mkv
        width: 1920
        height: 1080
    output2:
        sink: /opt/edgeai-test-data/output/output_image_%04d.jpg
        width: 1920
        height: 1080
    output3:
        sink: remote
        width: 1920
        height: 1080
        port: 8081
        host: 127.0.0.1
        encoding: jpeg
        overlay-perf-type: graph

flows:
    flow0: [input2,model1,output0,[320,150,1280,720]]
```

يمكنك تعديل ملف YAML أعلاه وفقاً لاحتياجاتك.

<ParamField body="TITLE" default="Image Classification" required>
عنوان التطبيق. يُستخدم كمرجع في مخرجات السجل وفي الواجهة.
</ParamField>

<ParamField body="LOG_LEVEL" default="2" required>
يحدد مستوى تفاصيل السجل. 0: الحد الأدنى، 5: debug
</ParamField>

<ParamField body="INPUTS" required>
مصادر بيانات الإدخال المراد معالجتها.
</ParamField>

<ParamField body="INPUT_SOURCE" default="<device-path>,<file-path>" required>
مسار مصدر الإدخال.
</ParamField>

<ParamField body="INPUT_FORMAT" default="jpeg,h264" required>
صيغة بيانات الإدخال. على سبيل المثال: jpeg, h264
</ParamField>

<ParamField body="INPUT_WIDTH" default="1280" required>
عرض صورة الإدخال (بالبكسل)
</ParamField>

<ParamField body="INPUT_HEIGHT" default="720" required>
ارتفاع صورة الإدخال (بالبكسل)
</ParamField>

<ParamField body="INPUT_FRAMERATE" default="30" required>
معدل أطر الإدخال (FPS)
</ParamField>

<ParamField body="INPUT_LOOP" default="True,False">
هل سيتكرر بحلقة؟
</ParamField>

<ParamField body="MODELS" required>
النماذج المستخدمة
</ParamField>

<ParamField body="MODEL_PATH" default="<file-path>" required>
 مسار ملف النموذج.
</ParamField>

<ParamField body="MODEL_TOPN" default="5" required>
 عدد التوقعات top-N المأخوذة من النموذج.
</ParamField>

<ParamField body="OUTPUTS" required>
أهداف المخرجات
</ParamField>

<ParamField body="OUTPUT_SINK" default="remote,kmssink,<file-path>" required>
مسار المخرجات
</ParamField>

<ParamField body="OUTPUT_WIDTH" default="1920" required>
عرض دقة البث (بالبكسل)
</ParamField>

<ParamField body="OUTPUT_HEIGHT" default="1080" required>
ارتفاع دقة البث (بالبكسل)
</ParamField>

<ParamField body="OUTPUT_HOST" default="127.0.0.1">
عنوان IP للمضيف الذي سيتم البث إليه
</ParamField>

<ParamField body="OUTPUT_PORT" default="8081">
رقم منفذ البث
</ParamField>

<ParamField body="OUTPUT_ENCODING" default="jpeg,h264" required>
صيغة صور البث
</ParamField>

<ParamField body="OUTPUT_OVERLAY_PERF_TYPE" default="graph">
نوع overlay لرسم الأداء
</ParamField>

<ParamField body="FLOWS" required>
يعرّف تدفق البيانات.
</ParamField>

<ParamField body="FLOW" default="[input2, model1, output0, [320,150,1280,720]]" required>
يعرّف تدفق البيانات: input → model → output. يمكنك اختيارياً تحديد ROI (x,y,width,height).
</ParamField>

<Warning>
  قبل بدء خطوات معالجة الصور، تأكد من تسجيل الدخول بصفتك `root` ومن تحميل متغيرات البيئة.
</Warning>

<CodeGroup>

  ```bash Python
  cd /opt/edgeai-gst-apps/apps_python && ./app_edgeai.py ../configs/image_classification.yaml
  ```

  ```bash C++
  # جمّع المشروع
  cd /opt/edgeai-gst-apps && ./scripts/compile_cpp_apps.sh

  # بعد تجميع التطبيق باستخدام السكربت، يمكنك تشغيل التطبيق النموذجي باستخدام الأمر أدناه.
  cd /opt/edgeai-gst-apps/apps_cpp && ./bin/Release/app_edgeai ../configs/image_classification.yaml
  ```

</CodeGroup>

لإنهاء معالجة الصور لاحقاً، يمكنك إيقافها بالضغط على التركيبة `CTRL + C` مرة واحدة.

إذا لم تُجرِ أي تغيير على ملف الإخراج في ملف YAML، فيمكنك الوصول إلى المخرجات عبر
`/opt/edgeai-test-data/output/output_video.mkv`.

## الدمج في كود Python الحالي لديك

يشغّل TensorFlow Lite النماذج افتراضياً على وحدة المعالجة المركزية (CPU) للجهاز.

"Delegate" (المفوض/الوكيل) هو آلية "تفويض" جزء من حسابات نموذج TFLite أو كلها إلى عتاد أكثر تخصصاً بدلاً من
CPU. لاستخدام هذا العتاد المتخصص (مثل مسرّعات معالجة الصور الموجودة داخل لوحة تطوير T3 Gemstone O1)، يجب
عليك تحميل ملف المكتبة المشتركة المطلوب (.so و.dll وما إلى ذلك).

<Warning>
  قبل بدء خطوات معالجة الصور، تأكد من تسجيل الدخول بصفتك `root` ومن تحميل متغيرات البيئة.
</Warning>
