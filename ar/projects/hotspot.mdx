---
title: 'Wi-Fi Hotspot'
description: 'تحويل لوحة Gemstone إلى نقطة وصول Wi-Fi آمنة'
---

إذا قمت بتوصيل لوحة Gemstone بالمودم الذي يزوّد منزلك بالإنترنت عبر كابل Ethernet، فيمكنك استخدام شريحة Wi-Fi
الموجودة على اللوحة لتحويلها إلى نقطة وصول لاسلكية (Hotspot).

بهذه الطريقة، يمكنك جعل الأجهزة في منزلك تتصل مباشرة بالشبكة اللاسلكية (Wi-Fi) التي تبثها عتاد Gemstone دون المساس
بأي إعدادات للمودم أو DNS خاصة، وتمرير اتصالات الإنترنت عبر واجهة Ethernet لتستفيد تلقائياً من حماية جدار الحماية
(Firewall) القائم على AdGuard Home.

## إنشاء نقطة اتصال Wi-Fi

لإنشاء شبكة لاسلكية من طرفية الجهاز:

1. تحقق من اسم واجهة الشبكة اللاسلكية لديك (عادةً `wlan0`). يمكنك استخدام الأمر `ip a` أو `ifconfig` لمعرفة ذلك.
2. عدّل الأمر التالي بما يناسبك وشغّله لإنشاء شبكتك:

```bash
# تأكد من أن قسم كلمة المرور لا يقل عن 8 أحرف
sudo nmcli device wifi hotspot ifname wlan0 ssid "Gemstone_Guvenli_Ag" password "GucluSifrem123"
```

* `ssid`: يمثل اسم الشبكة الذي سيظهر للأجهزة المحيطة.
* `password`: هي كلمة المرور المطلوبة للاتصال بشبكتك.

تُضبط اتصالات نقطة الاتصال (Hotspot) التي تُنشأ باستخدام Network Manager (`nmcli`) افتراضياً بحيث تشارك الإنترنت
الموجود على الجهاز (مثل Ethernet) عبر Wi-Fi.

## تفعيل مشاركة الإنترنت (NAT)

إذا كانت الأجهزة قادرة على الاتصال بالشبكة التي أنشأتها ولكن لا يمكنها الوصول إلى الإنترنت، فقد تحتاج إلى توجيه
(مشاركة) اتصال Ethernet (الإنترنت السلكي) الموجود على Gemstone إلى شبكة Wi-Fi.

استخدم الأوامر التالية لتعيين خاصية مشاركة الإنترنت لاتصال نقطة الاتصال لديك. (حدّث اسم الاتصال باسم `ssid`
الذي أعطيته عند إنشاء نقطة الاتصال):

```bash
# اضبط طريقة IPv4 للاتصال على "shared"
sudo nmcli connection modify "Gemstone_Guvenli_Ag" ipv4.method shared

# أعد تشغيل شبكة نقطة الاتصال حتى تسري التغييرات
sudo nmcli connection up "Gemstone_Guvenli_Ag"
```

### خطوة إضافية: تفعيل إعادة توجيه IP (IP Forwarding)

في حالات نادرة قد يكون إعادة توجيه IP على مستوى نواة (Kernel) Linux مغلقاً. إذا لم يتم توزيع الإنترنت بعد،
فعّل إعادة توجيه IP:

1. للتفعيل المؤقت:

   ```bash
   sudo sysctl -w net.ipv4.ip_forward=1
   ```

2. لجعل هذا الإعداد دائماً، افتح ملف `/etc/sysctl.conf` بمحرر نصوص وبصلاحيات (مثل `nano`)، واحذف علامة `#` من
   بداية السطر `#net.ipv4.ip_forward=1` الموجود داخله ثم احفظ الملف. لتأكيد التغييرات شغّل الأمر التالي:

   ```bash
   sudo sysctl -p
   ```

بعد الإعداد، عندما تتصل بالشبكة من هاتفك أو جهاز الكمبيوتر ستمر حركة المرور لديك مباشرة عبر Gemstone، وستُحظر
الإعلانات وسيُوفَّر الإنترنت لديك دون انقطاع عبر خط Ethernet.
